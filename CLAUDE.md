## Commands

Native Linux apps (the live work since 2026-10-28; Linux Native Apps plan):

- Build one app: `cargo build --release -p <package>` (`mp-shell`, `mp-player`, `mp-files`; shared crates `mp-theme`, `mp-ui`). `~/.local/bin/mp-*` are links into `target/release`, so the build is the install; `mp-theme` and `mp-wallpaper` are copies, re-install them.
- Restart: the strip via `systemctl --user restart mp-shell` (never `setsid`), its log via `journalctl --user -u mp-shell`; other apps close + reopen.
- Tests: `cargo test -p <crate>` (e.g. `cargo test -p mp-files`). `mp-ui` alone does not build (no drawing engine is picked without an app): `cargo test --release -p mp-ui -p mp-shell`.
- Memory gate: `ram_check` (limits in `~/.config/ram_check/limits`).
- Closeout: `Infrastructure/Template/Close the Loop — Mortar & Pestle.md` in the Citadel vault.

Frozen Windows app (`web/`, `src-tauri/`; untouched until Linux Native Apps Phase 12, none of it runs on Linux):

- Install (root): `npm install`
- Install (web): `npm --prefix web install`
- Dev: `npm run tauri dev` — Vite HMR at `http://127.0.0.1:5173` + the Tauri desktop window
- Build: `npm run tauri build` — NSIS installer under `src-tauri/target/release/bundle/nsis/`
- Verify (one-command gate): `npm run verify` — runs `node scripts/verify.mjs`: the safe Rust integration-test set, both web checks, and a JS syntax gate. Green = ship-ready.
- A single Rust integration test: `cargo test --manifest-path src-tauri/Cargo.toml --test <name>` (targets: `integration`, `stt_roundtrip`, `capture_roundtrip`, `vault_io_sanity`, `health_grammar`, `transcode_integration`). NEVER `cargo test --tests` or `cargo test --lib` — BOTH SIGTERM the agent dev-sandbox (they compile the ~36 `#[cfg(test)]` lib unit-test mods). `scripts/verify.mjs` enumerates the safe `--test <name>` targets explicitly; see the hazard banner at its top. `transcode_integration` is COMPILE-ONLY there (`--no-run`): every test in it is `#[ignore]`d, and its exe cannot load on Windows at all — it is the one target importing `TaskDialogIndirect` (comctl32 v6, via `app_lib::asset_protocol` → tauri), and a manifest-less `cargo test` exe binds the legacy comctl32 5.82 in system32, dying at load with `0xc0000139 STATUS_ENTRYPOINT_NOT_FOUND`. Run its real tests only with an explicit `-- --ignored --test-threads=1` (needs ffmpeg on PATH) and expect that same load failure.
- Web checks (also run by `npm run verify`): `npm --prefix web run check-themes` (WCAG-AA contrast) and `npm --prefix web run check-drag` (drag-math invariants).

## Architecture

- The root `Cargo.toml` is a workspace of `crates/*` + `apps/*` (Linux Native Apps plan, Phase 5, 2026-10-29). One program and package per app, shared code built in:
  - `apps/shell` (`mp-shell`): the desktop strip, its menus, the side panel, notices (M&P Shell plan), and the music box in the top drawer (`apps/shell/src/music/`, its Music panel; it was `apps/library`, `mp-library`, until the Top Strip plan step 2, 2026-11-05: Malthaiel's ask so all four panels slide in one box).   - `apps/player` (`mp-player`): the music player (M&P Library plan).
  - `apps/files` (`mp-files`): the File Explorer, GNOME Files' design (File Explorer plan).
- `crates/mp-core` (vault folders + safe saving, frontmatter, markdown blocks, file watching, copied from `src-tauri`) was deleted 2026-11-09: no app used it (Fable Sweep row S1). The first app that needs the vaults gets it back: `git show 0337f6fd:crates/mp-core`.
- `crates/mp-theme`: two fixed colour sets into `~/.config/mp-theme/` (`colours.toml` for the apps, `niri.kdl`, `foot.ini`): light = hooxoo's Umbriel `config.toml` colours exactly, dark = each one's opposite (255 minus each part), `error` red in both; `mp-theme [dark|light|toggle]`. It no longer reads the wallpaper (his ask 2026-11-09, Noctalia Look; Material's TonalSpot and `material-colors` went). `crates/mp-ui`: what every app draws with: the rulebook (`style.rs`), colours, motion, icons, the default components listed under the rulebook, plus `ask` (the one pop-up box), `portal` (the desktop's Open window) and `turned` (text turned on its side).
- Toolkit: iced 0.14 drawn by tiny-skia on Wayland (niri); the strip and pop-ups are layer surfaces through `iced_exwlshell` 0.21.2; programs talk over D-Bus with zbus 6.2.
- `patches/` (root `[patch.crates-io]`): our copies of `softbuffer`, `iced_tiny_skia`, `exwlshellev` and `iced_exwlshell`. Why each exists and when to drop it is in the comment above that block.
- Frozen Windows app, untouched until Linux Native Apps Phase 12 (none of it runs on Linux): Tauri 2 in `src-tauri/`, React in `web/`, modules in `modules/`, its notes in `docs/`, and the sidecar crates `mortar-pestle-{capture,stt,broadcast,daemon}` + `nvenc-sys` (all in the workspace's `exclude` list). ## Conventions

- Several Claude chats share this checkout: `git status` first, and commit only your own files by exact path (`Infrastructure/Scripts/commit-mortar-pestle.py --paths ...` or `closeout.py --commit-paths ...` in the Citadel vault).
- A part one app needs stays in that app; a second app needing it moves it into a shared crate (`mp-ui` for anything drawn).
- Icons are SVGs copied into `apps/<app>/assets/`, each listed in that folder's `README.md`: Boxicons v3 Filled, every one (his ask 2026-11-10: Filled again; Tabler, Noctalia's, 2026-11-08 to 11-10). A state Boxicons lacks is made from Boxicons' own parts (bluetooth-slash, repeat-one).

## Gotchas

- Never write over `~/.local/bin/mp-*`: they are links into `target/release`, and a `cp` breaks the link so later builds install nothing.
- A half-made `apps/<new>` folder (another chat's) breaks every workspace build: wait for that chat, never touch it.
- zbus 6 `connection::Builder::name()` asks for a bus name with replace-and-be-replaced on by default, so a second start silently steals it. Every app sets `allow_name_replacements(false)`, and all but the strip's notices `replace_existing_names(false)` too.
- iced `text_input` captures Esc: a window that wants Esc takes it from `listen_with` whatever the status. iced 0.14 `mouse_area` `on_press` fires only when no child took the press.
- `iced_exwlshell` loads an app's fonts only with its first surface: text drawn through cosmic-text before the first layout falls back to another font.
- `.redraw_scope` (our `iced_exwlshell` patch) updates the app but rebuilds only the surfaces named; the others keep their old trees, which borrow the app's data. Name every surface whose `view` reads what that message changes, or the next relayout reads freed memory (Discord news with the box on Music: a cosmic-text "not a char boundary" panic, 2026-11-06).
- Memory: measure settled, not at open (a tiny-skia window adds its second picture buffer after a few redraws). Apps that open and shut big views call `mallopt` (`M_MMAP_THRESHOLD`, `M_ARENA_MAX`) in `main` (`apps/files`, `apps/shell` for its music box and Chat page) so freed memory goes back.
- `cargo test --tests` / `--lib` are unsafe only for the frozen `src-tauri` (they SIGTERM the agent sandbox); `cargo test -p <crate>` is safe.

## Env

The native apps read no `.env` file: only the standard `HOME`, `XDG_*`, `NIRI_SOCKET` and `PATH`, plus `FONTCONFIG_FILE`: `mp_ui::only_our_font()` points it at `~/.config/mp-shell/fonts.conf` when unset, so a start doesn't read every system font. `.env.example` (22 vars) belongs to the frozen app.
